# Fase 5.1 - Playbook Diario (Dia 1-3)

## Objetivo del dia

Cerrar el ciclo operativo diario con evidencia minima de estabilidad, incidentes y conversion.

## Checklist diario (09:00 -> 09:30)

- [ ] Verificar ejecucion automatica de tarea `PsyConnect-Phase5-OpsReport`.
- [ ] Revisar `docs/reports/YYYY-MM-DD_phase5_ops_report.md`.
- [ ] Validar bloque automatico `KPIs calculados automaticamente (DB)`.
- [ ] Completar KPIs manuales: error rate, p95, disponibilidad, TTD, MTTR.
- [ ] Revisar `docs/reports/YYYY-MM-DD_phase5_kpis.csv` para deltas relevantes.

## Checklist incidentes (si aplica)

- [ ] Registrar incidente en `docs/INCIDENT_P1_P2_TEMPLATE.md`.
- [ ] Definir mitigacion inmediata y owner.
- [ ] Actualizar seccion "Riesgos y Acciones" del reporte diario.

## Checklist de cierre del dia (18:00)

- [ ] Confirmar que no quedan incidentes criticos sin responsable.
- [ ] Marcar 1-3 acciones de mejora para backlog.
- [ ] Compartir resumen del dia con Tech Lead + Product.

## Criterio de exito Dia 1

- Reporte diario completo (auto + manual).
- Ningun P1 abierto sin plan de mitigacion.
- Deltas diarios revisados y comentados.
